# Introduction

The name Typecho is made up of two words, type and echo, and it is pronounced as those two sounds: `/taɪpˌ'ekoʊ/`.

Type means typing, and a blog is exactly that: a platform where we express ourselves on the web by typing. Echo means a reflection, feedback, a resonance. It is also the most common and most important function in PHP; most PHP enthusiasts probably began their PHP programming journey with `echo 'Hello World!';`.

The name says that Typecho is a blogging application. It is released under the [GPL version 2 license](https://opensource.org/license/gpl-2-0/), is built on PHP (PHP 7.4 or later is required), runs on a wide range of platforms, and supports several databases (Mysql / PostgreSQL / SQLite).

## About the documentation

This documentation is written for both users and developers. The user part covers the basic operation of the application; the developer part covers developing themes and plugins. If you run into a problem the documentation does not solve, ask on the [support forum at forum.typecho.org](https://forum.typecho.org); once you have confirmed a bug in the application, report it on [GitHub Issues](https://github.com/typecho/typecho/issues); you can also follow the Telegram channel [t.me/typechodev](https://t.me/typechodev). For how to choose a channel and how to describe a problem, see [Getting help](./guide/help/getting-help.md). If you find any mistake in the documentation, please [let us know](https://github.com/typecho/docs/issues).

As open-source software, our documentation is built in the open too: click the **Edit this page** button at the bottom left of any page to find the source of that page. You are welcome to help us improve the documentation for the benefit of more users.
