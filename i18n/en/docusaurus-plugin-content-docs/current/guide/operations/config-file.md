# config.inc.php and Constants

`config.inc.php` sits in the site root (next to `index.php`). It is generated by the installer and holds the database connection and a few base paths. Many of Typecho's advanced behaviours are adjusted by **defining constants** in this file; this page lists every constant available in 1.3.

The constants and the places that read them on this page correspond to Typecho 1.3.0; file paths are relative to the Typecho program root.

## What the installer generates

```php title="config.inc.php"
<?php
// site root path
define('__TYPECHO_ROOT_DIR__', dirname(__FILE__));

// plugin directory (relative path)
define('__TYPECHO_PLUGIN_DIR__', '/usr/plugins');

// theme directory (relative path)
define('__TYPECHO_THEME_DIR__', '/usr/themes');

// admin directory (relative path)
define('__TYPECHO_ADMIN_DIR__', '/admin/');

// register autoload
require_once __TYPECHO_ROOT_DIR__ . '/var/Typecho/Common.php';

// init
\Typecho\Common::init();

// config db
$db = new \Typecho\Db('Pdo_Mysql', 'typecho_');
$db->addServer(array (
  'host' => 'localhost',
  'port' => 3306,
  'user' => 'typecho',
  'password' => '******',
  'charset' => 'utf8mb4',
  'database' => 'typecho',
  'engine' => 'InnoDB',
  'sslCa' => NULL,
  'sslVerify' => false,
), \Typecho\Db::READ | \Typecho\Db::WRITE);
\Typecho\Db::set($db);
```

(The template is `install_config_file()` in `install.php`.)

| Part | Details |
|---|---|
| The 4 `define`s | The site root, and the paths of the plugin, theme and admin directories relative to the root. The first three are usually left alone; the admin directory can be changed, see [Custom admin path](./admin-dir.md) |
| `Common.php` and `Common::init()` | Register autoloading and initialize output buffering and the default exception output; must be kept |
| `new \Typecho\Db(adapter, table prefix)` | The adapter is one of `Pdo_Mysql`, `Mysqli`, `Pdo_Pgsql`, `Pgsql`, `Pdo_SQLite` and `SQLite` |
| `addServer(connection parameters, purpose)` | Connection parameters are listed below; the purpose `Db::READ \| Db::WRITE` means this server is used for both reads and writes |

Connection parameter keys:

| Database | Keys |
|---|---|
| MySQL | `host`, `port`, `user`, `password`, `charset`, `database`, `engine`, `sslCa`, `sslVerify`. When `host` contains `/` it is treated as a Unix socket path, and `port` is then `null` |
| PostgreSQL | `host`, `port`, `user`, `password`, `charset`, `database`, `sslVerify` |
| SQLite | `file`: the absolute path of the database file |

To switch database servers or change the password, edit the values here directly.

:::danger Protect this file
`config.inc.php` contains the database password. It is a PHP file, so requesting it through the web normally returns a blank page; but do not leave copies with non-`.php` names such as `config.inc.php.bak` in the site directory, and do not commit it to a public code repository.
:::

## How to add constants

Add the `define(...)` calls at the end of the file, for example:

```php
// Custom settings below
define('__TYPECHO_SECURE__', true);
define('__TYPECHO_THEME_WRITEABLE__', false);
```

Each constant can be defined only once. Upgrading Typecho does not modify `config.inc.php`, so your custom constants are kept.

## Constants you should not define yourself

| Constant | Details |
|---|---|
| `__TYPECHO_ADMIN__` | Marks admin pages; defined by `admin/common.php:6` |
| `__TYPECHO_CLASS_ALIASES__` | Mapping table from old class names to new ones; defined by `var/Widget/Init.php:57` |
| `__TYPECHO_DB_HOST__`, `__TYPECHO_DB_PORT__`, `__TYPECHO_DB_NAME__`, `__TYPECHO_DB_USER__`, `__TYPECHO_DB_PASS__`, `__TYPECHO_DB_CHAR__` | Only appear in an old comment in `var/Typecho/Db.php`; the program does not read them. Put database connection settings in `addServer()` |

## Read/write splitting

`addServer()` can be called several times, each with its own purpose. For example, to send reads to a read-only replica:

```php
$db = new \Typecho\Db('Pdo_Mysql', 'typecho_');
$db->addServer([/* primary connection parameters */], \Typecho\Db::WRITE);
$db->addServer([/* read-only replica connection parameters */], \Typecho\Db::READ);
\Typecho\Db::set($db);
```
