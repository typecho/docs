# Development Overview

This part is for people who write code on top of Typecho: theme authors, plugin authors, and contributors to Typecho itself. If you only use Typecho to build and run a site, see the "Guide" in the top left.

## Sections

The development documentation is divided by the way you extend Typecho, listed in this order in the left sidebar:

- **Theme Development**: writing and publishing themes.
- **Plugin Development**: writing and publishing plugins.
- **Reference**: lookup tables and API listings.
- **Core Development**: the structure of Typecho itself and how it is developed.
- **Contributing**: how to submit changes to Typecho and to this documentation.

## How to read

- To write a theme, start with "Theme Development"; to write a plugin, start with "Plugin Development". Both link to "Reference" where needed.
- "Reference" is meant for lookup; there is no need to read it from start to finish.
- Chinese and English terms in this documentation follow the [glossary](../glossary.md).
