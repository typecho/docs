# Glossary

| 中文 | English | Notes |
|---|---|---|
| 文章 | post | `contents.type = post` |
| 独立页面 | page | Shown as "独立页面" (Pages) in the admin menu; pages can be nested in a tree |
| 附件 / 文件 | attachment | The admin menu calls it "文件" (Files) |
| 草稿 | draft | `post_draft` / `page_draft` |
| 修订版本 | revision | New type in 1.3 |
| 分类 / 标签 | category / tag | Collectively called metas; not translated as "元数据" (metadata) |
| 评论 / 引用通告 / Pingback | comment / trackback / pingback | Pingback is not translated |
| 控制台 | Console | Admin home page |
| 永久链接 | permalink | |
| 地址重写（伪静态） | URL rewriting | In Chinese pages, "伪静态" is added in parentheses on first use |
| 主题 / 模板 | theme / template | A template is a single PHP file within a theme |
| 自定义字段 | custom field | |
| 插件 | plugin | |
| 钩子 / 句柄 | hook / handle | A handle is the argument to `factory()` |
| Widget | widget | Not translated; kept in English |
| Action | action | `/action/<name>`; not translated |
| 路由 | route | |
| 面板 | panel | `addPanel` |
| 管理员 / 编辑 / 贡献者 / 关注者 / 访问者 | administrator / editor / contributor / subscriber / visitor | Roles |
| 站点地址 | site URL | `siteUrl` |
| 语言包 | language pack | `usr/langs` |
