# 开发概览

这一部分面向在 Typecho 之上写代码的人：主题作者、插件作者，以及参与 Typecho 本身开发的贡献者。只是使用 Typecho 搭建和管理站点，请看左上角的“使用指南”。

## 内容分区

开发文档按扩展方式分为以下几个部分，在左侧边栏中依次排列：

- **主题开发**：编写和发布主题。
- **插件开发**：编写和发布插件。
- **参考**：供查阅的对照表与接口清单。
- **核心开发**：Typecho 程序本身的结构与开发方式。
- **参与贡献**：如何向 Typecho 和本文档提交改动。

## 如何阅读

- 写主题从“主题开发”开始，写插件从“插件开发”开始；两者都会在需要时链到“参考”。
- “参考”适合查阅，不必从头读起。
- 文档中的中英文术语以[术语表](../glossary.md)为准。
