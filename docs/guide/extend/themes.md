# 安装与设置主题

主题（外观）决定站点前台的样子。主题管理在后台“控制台 → 外观”（`admin/themes.php`），只有管理员能使用。

## 自带的两个主题

| 目录 | 后台显示的名称 | 说明 |
|---|---|---|
| `usr/themes/default` | Typecho Replica Theme | 经典的默认主题，安装后默认启用 |
| `usr/themes/classic-22` | Classic 22 | 1.3 新增的官方主题，基于 Pico CSS 2，支持浅色 / 深色外观 |

两者的设置项：

| 主题 | 界面名称 | 字段 | 说明 |
|---|---|---|---|
| default | 站点 LOGO 地址 | `logoUrl` | 填图片地址，显示在站点标题前 |
| default | 侧边栏显示 | `sidebarBlock[]` | 复选框：显示最新文章、显示最近回复、显示分类、显示归档、显示其它杂项（默认全选） |
| classic-22 | 网站 Logo | `logoUrl` | 填图片地址，显示 Logo |
| classic-22 | 外观风格 | `colorSchema` | 自动、浅色、深色、自定义；“如果选择了自定义，主题将使用 theme.css 的样式” |

## 安装主题

后台**没有**上传主题的功能，需要自己把文件放到服务器上：

1. 下载主题，解压得到一个目录；
2. 把整个目录上传到 `usr/themes/` 下，例如 `usr/themes/mytheme/`；
3. 到“控制台 → 外观”，新主题就会出现在“可以使用的外观”列表中。

一个目录要被识别为主题，里面至少要有 `index.php`，并且文件开头的注释写明主题信息，列表中显示的名称、作者、版本、描述都取自这里：

```php
<?php
/**
 * 主题的简短描述
 *
 * @package 主题名称
 * @author 作者
 * @version 1.0
 * @link https://example.com
 */
```

目录中名为 `screenshot.png`（也可以是 jpg、gif、webp 等）的图片会作为截图显示。目录放好后不需要任何安装步骤，刷新外观页面即可看到。

下载 GitHub 上的主题时，解压出的目录名常带有 `-main`、`-master` 后缀。主题对目录名没有硬性要求，但主题设置和自定义模板都按目录名保存，建议改成主题作者说明的名称再上传。

## 切换主题

在列表中点击要使用的主题的“启用”，提示“外观已经改变”。当前使用的主题没有“启用”链接。

:::caution 切换主题会删除原主题的设置
启用新主题时，**原来那个主题的设置会被删除**，新主题的设置项恢复为默认值。例如在 `default` 中填写了“站点 LOGO 地址”，切换到其他主题再切换回来，LOGO 地址已经清空。切换前请记下需要保留的设置。
:::

另外，切换主题时如果“站点首页”设为“直接调用模板文件”，会自动恢复为“显示最新发布的文章”，见[阅读设置](../settings/reading.md#front-page)。

### 当前主题的目录不见了

如果当前主题的目录被删除或改名，前台会**自动改用 `default` 主题**显示（因此不要删除 `default` 主题），外观页面顶部会提示：

> 检测到您之前使用的 "某某" 外观文件不存在，您可以重新上传此外观或者启用其他外观。

重新上传这个主题并刷新页面，提示消失；如果启用其他主题，原主题的设置数据会被删除。

## 主题设置页 {#config}

主题在 `functions.php` 中定义了 `themeConfig()` 时，外观页面上方会出现“设置外观”标签（`admin/options-theme.php`）。填写后点击“保存设置”，提示“外观设置已经保存”。设置保存在数据库 `options` 表中名为 `theme:主题目录名` 的一行里。

设置项的含义由主题决定，请看主题自己的说明。

## 在线编辑主题文件 {#editor}

外观页面上方的“编辑当前外观”（`admin/theme-editor.php`）可以直接在浏览器中修改主题文件：

- 左侧列出主题目录中的 `.php`、`.js`、`.css` 文件（不包括子目录）；
- 点击文件名打开，修改后点击“保存文件”，提示“文件 某某 的更改已经保存”；文件本身不可写时，按钮位置显示“此文件无法写入”；
- 列表中其他主题的“编辑”链接可以编辑未启用的主题。

编辑器没有撤销、版本记录或语法检查。在 `functions.php` 等 PHP 文件中写错一个字符，就可能让前台或后台都无法打开，这时只能通过 FTP / SSH 改回去。修改前请备份文件。

### 关闭在线编辑器：`__TYPECHO_THEME_WRITEABLE__`

在 `config.inc.php` 中加入：

```php
define('__TYPECHO_THEME_WRITEABLE__', false);
```

加入后，外观页面上方只剩“可以使用的外观”和“设置外观”两个标签，列表中的“编辑”链接消失，直接访问 `theme-editor.php` 返回 404。主题设置页不受影响。生产环境建议关闭，原因见[安全加固](../operations/security.md#theme-editor)。

## 主题出问题时

前台空白或 500 时，先切回 `default` 主题确认是否是主题的问题；后台也打不开时，可以通过数据库修改当前主题，方法见[调试与排错](../operations/debugging.md#isolate)。
