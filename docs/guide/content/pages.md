# 独立页面

独立页面适合“关于”“友情链接”“留言板”这类不按时间排列的内容。在“撰写 → 创建页面”（`admin/write-page.php`）新建，在“管理 → 独立页面”（`manage-pages.php`）管理。**编辑及以上角色**才能创建和管理页面，贡献者看不到这两个菜单。

## 页面与文章的区别

| | 文章 | 独立页面 |
|---|---|---|
| 谁能写 | 贡献者及以上 | 编辑及以上 |
| 出现在首页、归档、搜索、订阅源中 | 是 | 否，通常由主题列在导航里 |
| 分类、标签 | 有 | 没有 |
| 层级 | 无 | 可以有父页面，组成页面树 |
| 排序 | 按发布时间 | 按“页面顺序” |
| 自定义模板 | 无 | 可以为每个页面选择主题中的模板 |
| 公开度 | 公开、隐藏、密码保护、私密、待审核 | 只有公开、隐藏 |
| 默认地址 | `/archives/{cid}/` | `/{slug}.html` |
| 评论、自定义字段、附件、草稿与修订版本、自动保存 | 有 | 有，用法与[撰写文章](./posts.md)相同 |

## 编辑页面

编辑区与写文章相同：标题、网址缩略名、内容、[自定义字段](./custom-fields.md)，按钮为“预览页面”“保存草稿”“发布页面”。右侧“选项”栏：

| 界面名称 | 字段 | 说明 |
|---|---|---|
| 发布日期 | `date` | 同文章；设为将来的时间，页面到时才能访问 |
| 页面顺序 | `order` | 数字。“为你的自定义页面设定一个序列值以后, 能够使得它们按此值从小到大排列” |
| 自定义模板 | `template` | 列出当前主题中声明为自定义模板的文件，“不选择”则用主题的 `page.php` |
| 父级页面 | `parent` | 选择后“此页面将作为子页面呈现” |
| 公开度 | `visibility` | 公开、隐藏。隐藏的页面不出现在主题的页面列表里，但知道地址仍可以访问 |
| 权限控制 | `allowComment`、`allowPing`、`allowFeed` | 同文章 |

**网址缩略名**决定页面地址。默认规则是 `/{slug}.html`，例如缩略名 `links` 对应 `/links.html`；不填时自动生成：新建时取标题中的英文字母、数字（用 `-` 连接），标题里没有这些字符（例如纯中文标题）就用页面 ID（`var/Widget/Base/Contents.php` 的 `applySlug()`）。页面地址的规则在“设置 → 永久链接”的“独立页面路径”中修改，可用参数有 `{cid}`、`{slug}`、`{directory}`，其中 `{directory}` 是包含所有父页面缩略名的多级路径，适合页面树。

## 页面树 {#tree}

1.3 起页面可以有父页面，组成多级结构：

- 在“父级页面”中选择一个页面，当前页面就成为它的子页面；
- “管理 → 独立页面”的“子页面”列：没有子页面时显示“新增”，点击直接为它新建子页面（`write-page.php?parent=页面ID`，父级页面已预先选好）；有子页面时显示“一个页面”“N个页面”，点击进入子页面列表（`manage-pages.php?parent=页面ID`），标题显示为“管理 关于 的子页面”；
- 删除一个有子页面的页面时，它的子页面会上移一级，挂到被删页面的父页面下（顶级页面的子页面变成顶级页面）。

## 排序

页面在主题中通常按“页面顺序”从小到大排列，有两种设置方法：

1. 编辑页面时填写“页面顺序”；
2. 在“管理 → 独立页面”中直接**拖动行**。松开后，当前列表中的页面按显示顺序被重新编号为 1、2、3……，会覆盖之前手填的数字。拖动只在同一层级的列表中进行，要调整子页面，先进入子页面列表。

## 自定义模板 {#template}

主题可以提供多个页面模板。模板就是主题目录中的一个 PHP 文件，文件开头的注释里写有 `@package custom`，注释的第一行是模板在下拉框中显示的名称，例如 `usr/themes/default/page-links.php`：

```php
<?php
/**
 * 友情链接模板
 *
 * @package custom
 */
if (!defined('__TYPECHO_ROOT_DIR__')) exit;
$this->need('header.php');
?>
<!-- 页面内容 -->
<?php $this->need('footer.php'); ?>
```

主题中有了这样的文件，“自定义模板”下拉框就会出现“友情链接模板”（`index.php` 除外）。选中后，这个页面在前台改用该文件输出。换主题后，如果新主题没有同名文件，页面会使用新主题的默认页面模板显示。

## 管理页面

“管理 → 独立页面”可以按关键字筛选；勾选后在“选中项”菜单中删除，或标记为公开、隐藏。

删除页面时，它的评论、自定义字段和修订版本一起删除，附件变成“未归档”文件；如果这个页面被设为站点首页（“设置 → 阅读”中的“站点首页”），首页会恢复为显示最新文章。
