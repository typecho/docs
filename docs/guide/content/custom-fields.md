# 自定义字段（编辑器侧）

自定义字段让你给一篇文章或一个页面附加额外的数据，例如副标题、封面图地址、阅读次数，由主题决定怎么显示。编辑器中“自定义字段”面板下方的提示“自定义字段可以扩展你的模板功能, 使用方法参见 帮助文档”就指向本页。

本页只讲在后台怎么填写。在主题模板中读取字段（`$this->fields->字段名`）的写法属于开发文档的主题部分，那一章还在编写中。

## 面板在哪里

文章和页面编辑器中，正文下方有一个可以展开的“自定义字段”区域。文章或页面已经有字段、或者主题预置了字段时，它默认展开。

每一行是一个字段：

| 界面元素 | 表单字段 | 说明 |
|---|---|---|
| 字段名称 | `fieldNames[]` | 只能由字母、数字、下划线组成，不能以数字开头（`^[_a-zA-Z][_a-zA-Z0-9]*$`），区分大小写 |
| 字段类型 | `fieldTypes[]` | 下拉框，四种类型，见下文 |
| 字段值 | `fieldValues[]` | 多行文本框 |
| 删除 | | 确认“确认要删除此字段吗?”后移除这一行 |

点击“+添加字段”增加一行。字段随“保存草稿”或“发布”一起保存：

- 字段名称留空的行会被忽略；不符合规则的名称，浏览器会立即提示，即使提交了，服务器也会丢弃这一行。
- 删除一行再保存，这个字段就从文章中删除。
- 对已发布的文章“保存草稿”时，字段也保存在[修订版本](./posts.md#drafts)里，发布后才生效。

## 四种字段类型 {#types}

| 下拉框中的名称 | 类型值 | 用途 | 保存方式 | 模板中读到的值 |
|---|---|---|---|---|
| 字符 | `str` | 文字、网址、HTML 片段等，最常用 | 原样保存在 `str_value` 列 | 字符串 |
| 整数 | `int` | 计数、排序权重、开关（0 / 1） | 用 PHP `intval()` 转换后保存在 `int_value` 列 | 整数 |
| 小数 | `float` | 评分、价格、坐标 | 用 `floatval()` 转换后保存在 `float_value` 列 | 小数 |
| JSON 结构 | `json` | 列表、键值对等结构化数据 | `json_encode()` 后保存在 `str_value` 列 | `json_decode()` 后的值 |

填写的值与模板中读到的值，示例：

| 字段 | 类型 | 填写 | 模板中读到 |
|---|---|---|---|
| `subtitle` | 字符 | `一个副标题` | `'一个副标题'` |
| `views` | 整数 | `42abc` | `42`（非数字部分被丢掉） |
| `rating` | 小数 | `4.5` | `4.5` |
| `meta` | JSON 结构 | `{"color":"red","size":[1,2]}` | 字符串 `'{"color":"red","size":[1,2]}'`，**不是数组**（见下方说明） |

整数和小数类型不会校验输入：填了不是数字的内容，保存为 `0` 或开头的数字部分，不会报错。

:::caution 1.3.0 中面板里的“JSON 结构”会被重复编码
在面板中选择“JSON 结构”时，填写的文本被当作一个**字符串**再做一次 `json_encode()`，所以模板读到的是原来那段文本，而不是解析后的数组。更麻烦的是，再次打开编辑器时，字段值显示为转义后的 `"{\"color\":\"red\",...}"`，每保存一次（包括保存修订版本）就多套一层转义。

在这个问题修复之前，建议：需要结构化数据时，在面板中选择“字符”类型填写 JSON 文本，由主题自己 `json_decode()`；或者使用主题预置的字段（见下节），由主题的复选框等多值控件产生 JSON 数据，这种情况保存和读取都正常。
:::

## 主题预置的字段 {#theme-fields}

主题可以在 `functions.php` 中预先定义字段，它们显示在面板最上方，带有说明文字，形式可以是文本框、下拉框、复选框等，不需要手动输入字段名和类型。

- 主题通过 `themeFields()`（文章和页面都显示）、`themePostFields()`（只在文章中显示）或 `themePageFields()`（只在页面中显示）定义这些字段。
- 预置字段一般保存为“字符”类型；多选控件（例如复选框）的值保存为“JSON 结构”，模板中读到数组。例如一个有“置顶”“热门”两个选项的复选框，全选后保存为 `["top","hot"]`，模板中读到 `['top', 'hot']`，再次编辑时两个选项保持勾选。
- 预置字段的名称不会再出现在下面的自由字段行中。
- 换成另一个主题后，原主题预置的字段不再以控件形式出现；已经保存的值仍在数据库中，会作为普通字段行显示，可以继续编辑或删除（原来是“JSON 结构”的字段，在面板中重新保存时同样会遇到上面的重复编码问题）。

插件也可以预置字段，或把某些字段设为只读——只读字段不在面板中显示，也不会被编辑器修改。
