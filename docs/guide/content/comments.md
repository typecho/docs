# 评论管理与审核

访客留下的评论，以及其他网站发来的引用通告和 Pingback，都在“管理 → 评论”（`admin/manage-comments.php`）中处理。评论表单要求、是否需要审核、反垃圾等选项在“设置 → 评论”中设置。

## 谁能管理哪些评论

| 角色 | 能管理的评论 |
|---|---|
| 管理员、编辑 | 全站所有评论（列表上方可以在“所有”“我的”之间切换） |
| 贡献者 | 只有**自己文章下**的评论 |
| 关注者 | 不能进入评论管理 |

## 评论、引用通告与 Pingback

三者都保存在 `comments` 表中，用 `type` 区分：

| | 评论 | 引用通告 | Pingback |
|---|---|---|---|
| 类型值 | `comment` | `trackback` | `pingback` |
| 从哪里来 | 访客在你的文章页面上填写评论表单 | 别的博客在发布文章时，主动向你文章的引用通告地址（文章地址 + `/trackback`）提交一条通知 | 别的网站的文章里链接了你的文章，对方程序通过 XML-RPC 的 `pingback.ping` 通知你；Typecho 会去抓取对方页面，确认里面确实有指向你的链接 |
| 称呼与内容 | 访客填写的称呼和正文 | 称呼是对方博客名，内容是对方提交的摘要（截取前 100 字） | 称呼是对方页面的标题，内容是从对方页面中提取的一段文字 |
| 后台显示 | 正常显示 | 作者名旁标“引用” | 作者名旁标“引用” |
| 能否在后台回复 | 能 | 不能 | 不能 |
| 前提 | 文章“允许评论” | 文章“允许被引用” | 文章“允许被引用”，且“设置 → 基本”中的“XMLRPC 接口”为“打开”（`allowXmlRpc = 2`），见[订阅源与离线客户端](./feeds-xmlrpc.md#xmlrpc) |

反过来，你发布文章时：在编辑器“引用通告”中填写的地址会收到引用通告；正文中链接到的其他网站会收到 Pingback（对方支持的话）。

## 三种状态

| 标签页 | 状态值 | 含义 |
|---|---|---|
| 已通过 | `approved` | 显示在前台，计入文章的评论数 |
| 待审核 | `waiting` | 不显示，等待处理；标签页上显示数量 |
| 垃圾 | `spam` | 不显示；标签页上显示数量 |

新评论是什么状态，取决于“设置 → 评论”：

- 勾选“所有评论必须经过审核”（`commentsRequireModeration`）：新评论都是“待审核”；
- 只勾选“评论者之前须有评论通过了审核”（`commentsWhitelist`）：同一称呼和邮箱以前有过已通过的评论，直接通过，否则待审核；
- 两项都不勾选（默认）：直接通过，访客评论立即显示。

文章作者本人和编辑、管理员在前台发表的评论总是直接通过。

文章的评论数（`commentsNum`）**只统计已通过的评论**，把一条评论或引用标记为垃圾、待审核后，文章的评论数随之减少。

## 列表与筛选

每条评论显示头像、称呼、邮箱、网址、IP 地址、时间、所属文章（“于 文章标题”）和内容。可以用关键字筛选；在文章或页面列表中点击评论数，可以只看那篇内容的评论（`manage-comments.php?cid=文章ID`）。

## 单条操作

每条评论下方有一组链接，当前状态对应的那一项显示为灰色：

| 操作 | 说明 |
|---|---|
| 通过 / 待审核 / 垃圾 | 切换状态 |
| 编辑 | 在列表中直接修改“用户名”“电子邮箱”“个人主页”和“内容”，点击“提交”保存 |
| 回复 | 只对评论显示。在下方输入框中填写内容，点击“回复”。回复以你的账号身份发表、直接通过，作为这条评论的子评论显示（主题支持嵌套评论时） |
| 删除 | 确认“你确认要删除 某某 的评论吗?”后删除 |

回复会在 `comments` 表中新增一条 `parent` 指向原评论、作者为当前登录用户的已通过评论；编辑则直接替换原评论的内容。

## 批量操作

勾选多条评论（表头的复选框可以全选），在“选中项”菜单中选择：通过、待审核、标记垃圾、删除。

在“垃圾”标签页中另有“删除所有垃圾评论”按钮（确认“你确认要删除所有垃圾评论吗?”）。编辑和管理员在“所有”视图中点击时，删除全站的垃圾评论；在“我的”视图中，或者由贡献者点击时，只删除自己文章下的垃圾评论。

## 反垃圾的几条规则

- 一个 IP 发来的引用通告被标记为垃圾后，这个 IP 再发引用通告会直接得到 404。
- “设置 → 评论”中的反垃圾保护、检查来源页、同一 IP 评论间隔等选项可以挡住大部分机器人评论。
- 关闭某篇文章的评论或引用：在编辑器“高级选项”中取消“允许评论”或“允许被引用”，见[撰写文章](./posts.md)。
- 更强的过滤可以使用反垃圾插件。
