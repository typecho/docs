# 撰写文章

在后台“撰写 → 撰写文章”（`admin/write-post.php`）写新文章；在“管理 → 文章”中点击标题，编辑已有文章（`write-post.php?cid=文章ID`）。贡献者及以上角色可以写文章。

## 编辑器

| 区域 | 说明 |
|---|---|
| 标题 | 留空时保存为“未命名文档” |
| 网址缩略名 | 显示在标题下方的永久链接中，只有链接规则含 `{slug}` 时才有输入框。默认规则 `/archives/{cid}/` 用文章 ID，不需要填 |
| 文章内容 | Markdown 编辑器，上方有“撰写”“预览”两个标签页 |
| 自定义字段 | 内容下方可以展开，见[自定义字段](./custom-fields.md) |
| 右侧“选项”栏 | 发布日期、分类、标签、高级选项 |
| 右侧“附件”栏 | 上传和插入文件，见下文 |
| 按钮 | “预览文章”“保存草稿”“发布文章” |

### Markdown

个人设置中的“使用 Markdown 语法编辑和解析内容”（`markdown`）默认打开，这时编辑器有工具栏和快捷键：

| 按钮 | 快捷键 | 按钮 | 快捷键 |
|---|---|---|---|
| 加粗 | <kbd>Ctrl</kbd>+<kbd>B</kbd> | 数字列表 | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| 斜体 | <kbd>Ctrl</kbd>+<kbd>I</kbd> | 普通列表 | <kbd>Ctrl</kbd>+<kbd>U</kbd> |
| 链接 | <kbd>Ctrl</kbd>+<kbd>L</kbd> | 标题 | <kbd>Ctrl</kbd>+<kbd>H</kbd> |
| 引用 | <kbd>Ctrl</kbd>+<kbd>Q</kbd> | 分割线 | <kbd>Ctrl</kbd>+<kbd>R</kbd> |
| 代码 | <kbd>Ctrl</kbd>+<kbd>K</kbd> | 摘要分割线（插入 `<!--more-->`） | <kbd>Ctrl</kbd>+<kbd>M</kbd> |
| 图片 | <kbd>Ctrl</kbd>+<kbd>G</kbd> | 撤销 / 重做 | <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
| 全屏 / 退出全屏 | <kbd>Ctrl</kbd>+<kbd>J</kbd> / <kbd>Ctrl</kbd>+<kbd>E</kbd> | 保存 | <kbd>Ctrl</kbd>+<kbd>S</kbd> |

macOS 上用 <kbd>Cmd</kbd> 代替 <kbd>Ctrl</kbd>。

- 用 Markdown 写的文章，正文开头会带一个 `<!--markdown-->` 标记，前台显示时按 Markdown 解析；没有这个标记的文章按 HTML 输出（自动把空行转成段落）。
- 打开一篇不是用 Markdown 写的旧文章时，编辑器会问“这篇文章不是由Markdown语法创建的, 继续使用Markdown编辑它吗?”，选“是”之后保存，这篇文章就改为 Markdown。
- 关闭 `markdown` 后，编辑器是普通文本框，插入附件时插入的是 HTML 标签。已经用 Markdown 写的文章仍按 Markdown 显示。
- `<!--more-->` 之前的部分是摘要，主题的文章列表和“仅输出摘要”的订阅源会用到它。

### 发布日期

“发布日期”的格式是 `年-月-日 时:分`，例如 `2026-12-01 09:00`，按“设置 → 基本”中的时区理解。新文章留空时取发布那一刻的时间；编辑已有文章时保留原来的日期。把日期设在将来，就是定时发布，见[下文](#scheduled)。

## 草稿、自动保存与修订版本 {#drafts}

### 保存草稿

点击“保存草稿”（或按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>S</kbd>）时，按文章当前的情况保存成两种东西：

| 情况 | 保存为 | 编辑器顶部的提示 | 文章列表中 |
|---|---|---|---|
| 新文章，从没发布过 | 草稿，内容类型 `post_draft` | “当前正在编辑的是未发布的草稿” | 出现在“草稿”标签页 |
| 已经存在的文章（已发布、待审核、隐藏等） | 修订版本，内容类型 `revision`，挂在原文章下 | “你正在编辑的是保存于 某时间 的修订版, 你也可以 删除它” | 标题后显示“有修订版” |

修订版本是 1.3 新增的（见[1.3 新特性与变更](../getting-started/whats-new-1-3.md)），要点：

- **原文章不受影响**：保存修订版本后，前台显示的仍是上次发布的内容，分类、标签的文章数也不变。
- **每篇文章只有一份修订版本**，再次保存会覆盖它，不会形成历史版本列表。
- 点击“发布文章”后，修订版本的内容写回原文章，修订版本随即删除。
- 不想要这次修改，点提示中的“删除它”，就回到已发布的内容。
- 删除文章时，它的修订版本一并删除。

### 自动保存

在[个人设置](./profile.md#writing)中打开“自动保存”（`autoSave`，默认关闭）后，编辑器在你停止输入 **3 秒**后自动执行一次“保存草稿”，按钮左侧依次显示“尚未保存”“正在保存”“已保存 (时间)”；失败时显示“保存失败, 请重试”。自动保存走的是同一个保存流程，所以对已发布文章同样只生成修订版本，不会改动前台。

没打开自动保存时，有未保存的修改就离开页面，浏览器会提示“内容已经改变尚未保存, 您确认要离开此页面吗?”。

:::note
“已保存”后面的时间显示为 `16:50:08 PM` 这样的形式：24 小时制的时间后面又加了 AM/PM。这是显示问题（`var/Widget/Contents/Post/Edit.php` 中的 `format('H:i:s A')`），不影响保存。
:::

### 预览

“预览文章”在页面内打开前台样式的预览。内容有改动时，会先询问“修改后的内容需要保存后才能预览, 是否保存?”，保存（草稿或修订版本）后再预览，所以预览不会改变前台。

## 分类与标签

- **分类**：勾选一个或多个。新文章会预先勾选默认分类；如果全部取消勾选，保存时仍归入默认分类。分类的增删和默认分类的设置见[分类与标签](./categories-tags.md)。
- **标签**：输入标签名后按半角逗号 `,` 或回车，变成一个标签块；输入时会提示已有的标签，没有的会提示“此标签不存在, 按回车创建”，保存时自动新建。在输入框中打全角逗号“，”不会断开标签，但服务器保存时会把“，”当作分隔符处理。

## 高级选项

点击右侧的“高级选项”展开：

| 界面名称 | 字段 | 说明 |
|---|---|---|
| 公开度 | `visibility` | 公开、隐藏、密码保护、私密、待审核。**只有编辑及以上角色能看到这一项**，含义见[可见性与密码保护](./visibility.md) |
| 权限控制 → 允许评论 | `allowComment` | 关闭后这篇文章不再接受评论 |
| 权限控制 → 允许被引用 | `allowPing` | 关闭后不再接受引用通告（Trackback）和 Pingback |
| 权限控制 → 允许在聚合中出现 | `allowFeed` | 关闭后这篇文章不出现在 RSS / Atom 订阅源中 |
| 引用通告 | `trackback` | 填写要通知的对方文章的引用通告地址，每行一个；发布时发送 |

三个“允许”开关在新文章中的默认状态，来自[个人设置](./profile.md#writing)的“默认允许”。此外，“设置 → 评论”中如果开启了“在文章发布 N 天以后自动关闭评论”，过了期限的文章即使勾选了“允许评论”“允许被引用”，评论和引用也会关闭。

## 插入附件 {#attachments}

切换到右侧“附件”栏，把文件拖到“拖放文件到这里”区域，或点击“选择文件上传”。

- 1.3.0 中每次只能选择一个文件（同时选择多个文件是 1.3.0 之后才合并的改动，不在 1.3.0 中）。
- 上传成功的文件出现在列表中。**点击文件名**才会插入编辑器：图片插入为 Markdown 图片，其他文件插入为链接，地址以引用形式写在正文末尾，例如：

  ```markdown
  ![pic.png][1]

    [1]: https://example.com/usr/uploads/2026/10/3396430629.png
  ```

- 文件名后面的编辑图标打开文件的编辑页，删除图标删除文件。
- 文章已经保存过（有文章 ID）时，上传的文件马上归属到这篇文章；新文章在第一次保存或发布时归属。
- 允许上传哪些类型、文件大小限制、替换文件等，见[附件与文件管理](./attachments.md)。

## 发布

点击“发布文章”。

- 编辑及以上角色按“公开度”发布，默认为“公开”，完成后跳到文章列表，提示“文章 "标题" 已经发布”。
- **贡献者**没有“公开度”选项，文章一律进入“待审核”状态，提示“文章 "标题" 等待审核”。编辑或管理员在“管理 → 文章 → 待审核”中审核，勾选后在“选中项”菜单里选“标记为公开”。
- 贡献者再次编辑并发布一篇**已经通过审核**的文章，它会重新变成“待审核”，从前台消失，直到再次审核通过（`var/Widget/Contents/EditTrait.php` 的 `checkStatus()`：编辑以下角色发布的内容一律为 `waiting`）。

### 定时发布 {#scheduled}

把“发布日期”设为将来的时间，再点击“发布文章”（公开度为“公开”）即可。到了那个时间，文章自动出现在前台，不需要计划任务。在那之前：

- 访问文章地址返回 404，首页、分类、标签、归档、订阅源中都看不到它，作者本人登录后也看不到；
- 后台文章列表中它和普通文章一样显示，日期列显示将来的日期（如“12月1日”），**没有“定时”标记**；
- 它已经计入分类和标签的文章数，所以前台列表的篇数会比后台显示的少，见[分类与标签](./categories-tags.md#counts)。

:::caution 定时发布不是“待审核”
定时发布的文章，状态仍是 `publish`（公开），只是创建时间在将来。公开度中的“待审核”（`waiting`）是另一回事：待审核的文章在通过审核之前永远不会出现在前台，与日期无关。
:::

## 文章列表

“管理 → 文章”（`manage-posts.php`）：

- 上方标签页：“可用”（全部文章，含未发布的草稿）、“待审核”（带数量）、“草稿”。编辑及以上角色另有“所有”“我的”切换，默认是“我的”，切换结果会被记住；贡献者只能看到自己的文章。
- 状态列显示“待审核”“密码保护”“私密”“隐藏”“有修订版”等标记；公开的文章不显示标记。
- 可以按关键字和分类筛选。
- 勾选后，“选中项”菜单中有：删除、标记为公开、标记为待审核、标记为隐藏、标记为私密。

删除文章时，它的评论、自定义字段和修订版本一起删除；它的附件不会删除，而是变成“未归档”文件，见[附件与文件管理](./attachments.md#unattached)。
