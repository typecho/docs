# 可见性与密码保护

文章编辑器“高级选项”中的“公开度”（`visibility`）决定谁能在前台看到一篇文章。**只有编辑及以上角色**能看到并修改这个选项；贡献者发布的文章一律是“待审核”。独立页面的公开度只有“公开”和“隐藏”两项。

## 五种公开度

| 界面名称 | 保存的状态 | 含义 |
|---|---|---|
| 公开 | `publish` | 所有人可见 |
| 隐藏 | `hidden` | 不出现在任何列表中，但知道地址的人可以打开 |
| 密码保护 | `publish`，并设置“内容密码”（`password`） | 出现在列表中，但标题和内容要输入密码才能看到 |
| 私密 | `private` | 只有作者本人登录后可见 |
| 待审核 | `waiting` | 前台谁都看不到，等待编辑或管理员审核 |

选择“密码保护”后，下方出现“内容密码”输入框。

另外两种情况也会让文章在前台不可见：**草稿**（从未发布过，见[撰写文章](./posts.md#drafts)）和**定时发布**（公开，但发布日期在将来，见[撰写文章](./posts.md#scheduled)）。

## 在前台的表现

下表中“列表”指首页、分类、标签、作者、日期归档等文章列表页：

| | 列表 | 搜索结果 | 订阅源 | 打开文章地址 | 上一篇 / 下一篇 | 计入分类、标签文章数 |
|---|---|---|---|---|---|---|
| 公开 | 显示 | 显示 | 显示 | 200 | 显示 | 是 |
| 隐藏 | 不显示 | 不显示 | 不显示 | 200，所有人都能看 | 不显示 | 否 |
| 密码保护 | 显示为“此内容被密码保护” | 不显示 | **不显示** | 403，显示密码表单 | 不显示 | 是 |
| 私密 | 只对作者显示 | 只对作者显示 | 未登录时不显示，作者本人登录时显示 | 作者 200，其他人 404 | 不显示 | 否 |
| 待审核 | 不显示 | 不显示 | 不显示 | 404，作者本人也一样 | 不显示 | 否 |
| 定时发布（到时间前） | 不显示 | 不显示 | 不显示 | 404，作者本人也一样 | 不显示 | 是（提前计入） |

几点说明：

- **私密只看作者，不看角色**：其他管理员、编辑打开别人的私密文章也是 404。作者要先登录后台，再访问前台。
- **待审核的文章**可以在后台用编辑器的“预览文章”查看效果。
- 隐藏不等于保密：隐藏文章的地址一旦被分享，任何人都能打开。需要限制访问时，用“密码保护”或“私密”。
- 公开度和内容密码**不保护上传的附件**：附件页面和文件地址不检查所属文章的状态，知道地址的人都能打开，见[附件与文件管理](./attachments.md#attachment-page)。
- 文章改为私密或隐藏后，它已经通过的评论仍会出现在全站评论订阅源中，见[评论订阅源](./feeds-xmlrpc.md#comment-feed)。

## 密码保护的细节 {#password}

访客打开一篇密码保护的文章时：

- 页面返回 HTTP 403，标题显示为“此内容被密码保护”，正文位置是“请输入密码访问”的表单；
- 输入错误的密码，返回 403 和“对不起,您输入的密码错误”；
- 输入正确的密码后，浏览器得到一个名为 `protectPassword_文章ID` 的会话 Cookie，关闭浏览器前再访问这篇文章不必重复输入，列表页中这篇文章也会显示真实标题和内容；
- 在解锁之前，访客不能评论这篇文章（评论表单不显示）。

**不需要输入密码**就能看到内容的人：文章作者本人，以及所有编辑和管理员（登录状态下）。贡献者访问别人的密码保护文章，仍然需要输入密码。

密码保护文章**始终不进入订阅源**，即使已经输入过密码；搜索结果中也不会出现（作者本人登录时除外）。

:::note
解锁用的 Cookie 中保存的是密码原文，内容密码不要与任何账号密码相同。
:::

## 批量修改

编辑和管理员在“管理 → 文章”中勾选文章，用“选中项”菜单中的“标记为公开 / 待审核 / 隐藏 / 私密”批量修改（没有批量设置密码的选项）。标记会同步修改这篇文章的修订版本状态，并相应增减分类和标签的文章数。审核贡献者的投稿，就是把“待审核”的文章标记为公开；默认的“我的”视图中看不到别人的投稿，要先切换到“所有”，步骤见[撰写文章](./posts.md#publish)。
