# 后台概览

后台默认位于 `站点地址/admin/`（可以改名，见[自定义后台路径](../operations/admin-dir.md)）。顶部导航有四个菜单：**控制台、撰写、管理、设置**。每一项都有一个最低角色，角色不够的菜单项不会显示；直接输入地址访问，会得到“禁止访问”（HTTP 403）。

:::info 测试情况
本页的菜单和权限已在 Typecho 1.3.0 + Apache + PHP-FPM（PHP 8.5）+ SQLite 上，用管理员、编辑、贡献者、关注者四个账号逐页访问核对过，与 `var/Widget/Menu.php` 中的定义一致。
:::

## 菜单地图

角色从高到低依次是：管理员（administrator）> 编辑（editor）> 贡献者（contributor）> 关注者（subscriber）> 访问者（visitor）。“最低角色”的意思是这个角色和比它高的角色都能使用。各角色具体能做什么，见[权限分配表](./users.md#permission-table)。

| 菜单 | 子菜单 | 页面文件 | 最低角色 | 说明 |
|---|---|---|---|---|
| 控制台 | 概要 | `index.php` | 关注者 | 后台首页（网站概要） |
| | 个人设置 | `profile.php` | 关注者 | 见[个人设置](./profile.md) |
| | 插件 | `plugins.php` | 管理员 | 插件管理；插件的设置页（`options-plugin.php?config=`）不在菜单中 |
| | 外观 | `themes.php` | 管理员 | 主题管理；“编辑当前外观”（`theme-editor.php`）和“设置外观”（`options-theme.php`）不在菜单中 |
| | 备份 | `backup.php` | 管理员 | 见[备份与恢复](../operations/backup.md) |
| 撰写 | 撰写文章 | `write-post.php` | 贡献者 | 见[撰写文章](./posts.md) |
| | 创建页面 | `write-page.php` | 编辑 | 见[独立页面](./pages.md) |
| 管理 | 文章 | `manage-posts.php` | 贡献者 | 贡献者只能看到自己的文章 |

实测各角色看到的菜单：

| 角色 | 控制台 | 撰写 | 管理 | 设置 |
|---|---|---|---|---|
| 管理员 | 概要、个人设置、插件、外观、备份 | 撰写文章、创建页面 | 文章、独立页面、评论、分类、标签、文件、用户 | 基本、评论、阅读、永久链接 |
| 编辑 | 概要、个人设置 | 撰写文章、创建页面 | 文章、独立页面、评论、分类、标签、文件 | 不显示 |
| 贡献者 | 概要、个人设置 | 撰写文章 | 文章、评论 | 不显示 |
| 关注者 | 概要、个人设置 | 不显示 | 不显示 | 不显示 |

插件可以向这四个菜单添加自己的页面（`extending.php?panel=`），也可以新增顶级菜单；这些页面的最低角色由插件决定，默认是管理员。

## 不在菜单里的页面

下面这些页面只在打开时才在菜单中高亮，平时是隐藏的：

| 页面 | 最低角色 | 从哪里进入 |
|---|---|---|
| 编辑文章 `write-post.php?cid=` | 贡献者 | 文章列表中点击标题 |
| 编辑页面 `write-page.php?cid=`、新增子页面 `write-page.php?parent=` | 编辑 | 页面列表 |
| 编辑文件 `media.php?cid=` | 贡献者 | 编辑器“附件”栏或文件列表中的编辑图标 |
| 新增分类 `category.php`、编辑分类 `category.php?mid=` | 编辑 | 分类列表 |
| 新增用户 `user.php`、编辑用户 `user.php?uid=` | 管理员 | 用户列表 |
| 插件设置、编辑当前外观、设置外观 | 管理员 | 插件和外观页面 |
| 升级程序 `upgrade.php` | 管理员 | 只在程序文件比数据库版本新时可以打开，否则跳回控制台，见[升级](../getting-started/upgrade.md) |
| 欢迎 `welcome.php` | 关注者 | 见下节 |

## 欢迎页 `welcome.php`

账号第一次登录（从未登录过）时，后台会先跳转到“欢迎使用”页面，上面有三条快捷链接：“强烈建议更改你的默认密码”（跳到[个人设置](./profile.md)的改密码部分）、“撰写第一篇日志”（贡献者及以上）和“查看我的站点”（管理员；其他角色显示为“查看网站”）。点击“让我直接开始使用吧 »”进入控制台。

打开过欢迎页后，浏览器会记下一个 `__typecho_first_run` Cookie，之后不再跳转。管理员在已经登录过的情况下访问 `welcome.php` 会被直接送回控制台；其他角色随时都可以再打开这个页面。

## 控制台首页

“网站概要”显示“目前有 N 篇文章, 并有 N 条关于你的评论在 N 个分类中”，其中文章数和评论数都只统计**你自己**的，分类数是全站的。下面的快捷链接按角色显示：

- 贡献者及以上：撰写新文章；有待审核或垃圾评论时，显示“待审核评论”“垃圾评论”及数量；
- 管理员：另有更换外观、插件管理、系统设置。

右侧是“最近发布的文章”“最近得到的回复”和“官方最新日志”。有新版本时，管理员会在这里看到升级提示，见[升级](../getting-started/upgrade.md)。

## 登录与会话

- 登录框可以填**用户名或邮箱**（“用户名或邮箱”）。
- 同一个账号同一时间只能在一处登录：每次登录都会生成新的登录凭据，之前在其他浏览器或设备上的登录随即失效。实测在命令行用同一账号登录后，浏览器中的后台立刻回到了登录页。
- 被设为“访问者”（visitor）组的账号可以登录，但所有后台页面都返回 403，见[用户、角色与注册](./users.md#visitor)。
