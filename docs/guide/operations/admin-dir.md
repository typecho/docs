# 自定义后台路径

Typecho 的后台默认在 `/admin/`。把它改成别的名字，可以挡掉一部分针对 `/admin/login.php` 的自动扫描和暴力破解。需要做两件事：**改常量**和**重命名目录**。

改名后 `/admin/` 返回 404，登录、控制台和设置页都在新路径下使用。

## 步骤

以改成 `/manage-x7/` 为例。

1. 编辑网站根目录下的 `config.inc.php`，找到安装时生成的这一行：

   ```php
   define('__TYPECHO_ADMIN_DIR__', '/admin/');
   ```

   改成：

   ```php
   define('__TYPECHO_ADMIN_DIR__', '/manage-x7/');
   ```

2. 把网站根目录下的 `admin` 目录重命名为同样的名字：

   ```bash
   cd /srv/www/typecho
   mv admin manage-x7
   ```

3. 访问 `https://你的域名/manage-x7/` 登录。

两步要同时完成：只改常量，后台链接会指向不存在的目录；只改目录名，后台页面里生成的地址仍然指向 `/admin/`。

## 规则

| 规则 | 原因 |
|---|---|
| 新目录必须直接位于网站根目录下，只有一层 | 后台页面用 `__DIR__ . '/../config.inc.php'` 加载配置（`admin/common.php`），目录放深一层就找不到配置文件 |
| 常量的值与目录名一致，写成 `/目录名/` 的形式 | Typecho 用它生成后台地址（`var/Widget/Options.php` 中的 `___adminUrl()`），并在后台页面中从当前地址的末尾去掉这一段来计算网站根地址（`___rootUrl()`）。两者不一致时，后台的链接和表单地址都会出错 |
| 名字只用字母、数字、连字符 | 避免需要 URL 编码的字符 |

## 改了之后

- **登录表单的提交地址不变**。不管后台目录叫什么，登录都提交到 `/index.php/action/login`；改后台路径只是把登录页面藏起来，不能代替强密码。
- **主题可能会暴露新路径**。例如自带的 `default` 主题在侧边栏“其它”区块中显示“登录”链接（主题设置中的“显示其它杂项”），链接就是新的后台地址。不想公开时，在主题设置里取消这一项。
- **升级时替换你自己命名的目录**。[升级](../getting-started/upgrade.md)时要用新版本的 `admin/` 覆盖 `manage-x7/`：先删除 `manage-x7`，再把新包中的 `admin` 复制过来并改成 `manage-x7`。不要把新的 `admin/` 直接放进网站目录，否则会同时存在两套后台文件。
- **Web 服务器或 CDN 中针对 `/admin/` 的规则**（不缓存、访问限制等）要同步改成新路径。
- 第三方插件或主题如果在代码里写死了 `/admin/`，改名后会失效。Typecho 自身的代码没有写死后台路径，插件和主题需要自行检查。

## 恢复默认

把常量改回 `'/admin/'`，再把目录名改回 `admin`。
